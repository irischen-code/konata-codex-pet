# 泉此方 · Konata Codex Pet

让泉此方陪你写代码。一个以《幸运星》泉此方为主题、采用 Q 版手办质感的非官方同人桌面宠物。

**定稿版本：1.0.0**。图集对应已确认的 v9，保留身体起伏待机、闭眼叉腰、左右行走、拿面包、看漫画和举拳互动。

## 一句话安装

已发布到 [Codex Pets · 泉此方](https://codex-pets.net/#/pets/konata-preview)。复制下面这句话发给 Codex，即可让它帮你安装：

```text
请帮我安装泉此方宠物：npx codex-pets add konata-preview
```

也可以在已安装 Node.js 和 npm 的电脑上直接运行：

```bash
npx codex-pets add konata-preview
```

安装完成后，在客户端的宠物列表中选择「泉此方」；若列表未刷新，完全退出并重新打开客户端。需要支持第二版自定义宠物图集的桌面客户端。

不使用命令行也可以按下方的手动安装步骤复制文件，无需 Node.js 或 npm。

## 手动安装到另一台电脑

只需要复制 `pets/konata-preview/` 文件夹。无需 Node.js、npm、API Key 或聊天记录。

1. 在目标电脑安装支持本地自定义宠物、支持第二版图集的桌面客户端。
2. 下载仓库 ZIP 并解压，或解压单独的宠物安装包。
3. 将 `konata-preview` 整个文件夹放入下列 `pets` 目录。目录不存在时手动创建；如有同名宠物，先备份再替换。
4. 重新打开客户端，在宠物列表中选择「泉此方」。

| 环境 | 默认目标目录 |
| --- | --- |
| macOS | `~/.codex/pets/konata-preview/` |
| Windows（需兼容客户端，未实机验证） | `%USERPROFILE%\.codex\pets\konata-preview\` |
| 设置了自定义 `CODEX_HOME` | `<CODEX_HOME>/pets/konata-preview/` |

macOS：在 Finder 中按 **Command + Shift + G**，输入 `~/.codex/pets/`。Windows：在文件资源管理器地址栏输入 `%USERPROFILE%\.codex\pets\`。

放好后的结构必须是：

```text
pets/
└── konata-preview/
    ├── pet.json
    └── spritesheet.webp
```

不要多套一层 `konata-codex-pet/pets/`。文件夹名和 `pet.json` 中的 `id` 都保留为 `konata-preview`，这是为了与已安装版本保持一致；显示名称是「泉此方」。

也可以在另一台电脑上使用上方的一句话安装方式，无需手动迁移文件。以上方式不依赖账号同步。手机、网页端及其他未提供本地宠物加载功能的客户端不在本包验证范围内。

## 动作怎样触发

以下映射来自本次本机客户端检查，其他版本可能变化。

| 场景 | 动作 |
| --- | --- |
| 静默待机 | 脚部固定，上半身轻微升降与摆动；睁眼与闭眼叉腰直接切换 |
| 左右拖动宠物 | 对应方向的行走动作 |
| 鼠标悬浮 | 举拳、星星眼互动 |
| 任务等待用户输入或批准 | 拿面包 |
| 任务运行中 | 看漫画 |
| 任务完成且结果未读 | 托腮得意表情 |

看漫画、拿面包不是通过点击某个身体部位触发，也不是静默时随机播放。某些动作播放数轮后会返回待机，鼠标状态也可能覆盖当前动作。

## 兼容性与已知限制

- 已在作者的 macOS 桌面环境确认使用，验证客户端版本为 `26.908.40834`（本机应用包名 `ChatGPT.app`）。Windows 尚未实机验证。
- 需要支持 `spriteVersionNumber: 2` 的客户端；图集为 **1536 × 2288**，8 列 × 11 行，每格 **192 × 208**。
- 每行有效帧数为 `6, 8, 8, 4, 5, 8, 6, 6, 6, 8, 8`；空白格属于格式要求。
- 动作速度由客户端控制。本次验证的静默循环约为 6.6 秒，节奏比悬浮互动慢，不能通过修改 README 或增加图集列数来加速。
- 本包只包含资源文件，不修改应用程序，不包含后台程序或联网脚本。

## 常见问题

**列表里没有泉此方？**

检查目录是否多套了一层、两个文件是否齐全、客户端是否使用自定义 `CODEX_HOME`。完全退出并重新打开客户端；确认目标客户端支持本地图集第二版。

**出现裁切、上下串帧或背景方格？**

重新复制本包的原始 `spritesheet.webp` 和 `pet.json`。不要用预览 GIF、截图或其他版本的图集替换，也不要重设画布尺寸。

**还是旧版名称或旧动作？**

重新选择宠物并重启客户端。更新时两个文件应来自同一个发布包。

**怎样卸载？**

先切换到其他宠物，再移走 `pets/konata-preview/` 文件夹。
